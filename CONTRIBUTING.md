# Contributing

## Rules

1. Never commit real identity documents, bank data, criminal-record data or private agreements.
2. Use synthetic fixtures in tests.
3. Add tests for every financial calculation or state transition.
4. LLM output must be schema-validated and reviewable.
5. No AI-generated binding legal conclusion.
6. No payment execution path may bypass authorization checks.
7. Changes involving regulatory assumptions must update the compliance documentation and cite a primary source where possible.

## Commit style

Use focused commits such as:
- `feat: ...`
- `test: ...`
- `docs: ...`
- `fix: ...`
- `research: ...`
